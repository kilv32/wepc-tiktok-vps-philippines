## 菲律宾这款到底给了什么

产品名里的 native residential 是关键信息。它表示这个 IP 在归属查询里显示为菲律宾的住宅宽带段，而不是数据中心段。

TikTok 判断账号环境时会看 IP 的归属类型。机房 IP 在 ipinfo 一类工具里显示 Hosting，来源是数据中心，跟真实用户的家宽环境对不上，常见的表现是新号注册就弹验证、视频发出去冷启动流量接近 0。住宅 IP 来自家庭宽带段，归属地显示 Residential，风控评分相对低一些。这是行业里被反复验证的机制，但它降低的是“被一眼识别”的概率，不等于账号不会被封。内容、设备指纹、行为节奏同样在评分里。

公开资料里也把这款归入菲律宾双 ISP 一类。双 ISP 指的是 IP 同时具备两个运营商的网络属性，抗关联能力比单一住宅段再强一点。如果你要做的是菲律宾本地流量，IP 归属地和目标受众对得上，这是选它的第一个理由。

配置层面需要看清楚三件事：

1TB 月流量对纯发视频够用，对直播推流不算宽裕。按 5Mbps 码率估算，一小时直播大约消耗 2.2GB，1TB 理论上是 450 小时左右。听起来不少，但矩阵号同时开播、反复测试推流参数，消耗速度会比预期快。

50Mbps 带宽跑单路 1080p 直播够，跑多路或者边传素材边直播就紧张。官方标注超流量后限速 5Mbps，仍然可用，只是这个速度下直播画质会明显下降，发短视频、登录后台这类操作不受影响。

1 个 IPv4 意味着一台机器只能对应一个账号环境。做矩阵就得按号买机器，这笔账要提前算进去，不能指望一台机器挂五个号。

## 三个容易踩的坑

**① 1TB 用完是限速，不是断网，但直播会难受**

限速 5Mbps 之后机器还能用，能登录、能发视频、能刷后台。可如果你正在直播，5Mbps 意味着码率被压到很低，画面糊、掉帧都可能出现。做直播的话，流量监控要当成日常动作，别等提示超量了才发现。

**② 退款窗口只有 3 天加 10GB**

规则写得很清楚：使用时间在 3 天内、总流量低于 10GB，可以全额退到账户余额，或者原路退回但每单扣 AUD 10 手续费。超过 3 天或超过 10GB，就不支持原路退款了，只能按使用比例退到账户余额，余额不可提现。

10GB 对测试发视频够用，对测试直播推流偏紧。按 5Mbps 算，10GB 大约只够 4.5 小时直播。打算拿它做直播的，测试顺序要安排好：先测 IP 类型和登录环境，再测推流，别把流量浪费在无关操作上。

**③ 电信用户必须中转**

官方对这款的三网口径是移动 Excellent、联通 Average、电信 Recommended via relay。也就是说电信直连不是设计中的正常用法。不挂中转，你体验到的延迟和丢包跟“三网直连”的机器完全不是一回事，别拿别人的移动网络体验来预期自己的电信线路。

## 下单前后要核对的几件事

拿到机器第一件事是查 IP。用 ipinfo.io 或 pingip.cn 看归属和类型，显示 Residential 才算对；显示 Hosting 说明拿到的不是住宅段，及时开工单。

时区和系统语言要跟 IP 地区一致。菲律宾 IP 配中国时区、中文系统，环境本身就是矛盾的。

一个 IP 只养一个号，不频繁切换地区。新号先花 3–5 天做正常的浏览、点赞、评论，再开始发内容。

系统装好后开 BBR，对吞吐有实际帮助，尤其跨国线路。

退款窗口只有 3 天，测试要有优先级。先验 IP 类型，再验登录和后台，最后才测推流，别把 10GB 花在下载测速上。
